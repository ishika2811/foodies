# 🍔 Foodies – Full Stack Food Ordering Application

Foodies is a full stack food ordering application built using **Spring Boot**, **React**, and **MongoDB**, with **AWS S3** used for image storage.  
The project includes a **User Application**, an **Admin Panel**, and a **Backend API**.

---

## 🚀 Tech Stack

### Backend (API)
- Java 21
- Spring Boot 3
- Spring Security + JWT Authentication
- MongoDB
- AWS S3 (image upload)
- Maven

### Frontend (User App)
- React (Vite)
- Context API
- Axios
- CSS

### Admin Panel
- React (Vite)
- REST API integration
- Admin food & order management
